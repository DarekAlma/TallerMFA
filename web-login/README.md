# web-login

Sistema de login web (React + Vite) del laboratorio TallerMFA. Las instrucciones completas, incluido el despliegue en Vercel, están en el [README principal](../README.md#4-web-de-login-web-login-y-despliegue-en-vercel).

```bash
npm install
cp .env.example .env.local   # VITE_API_URL=http://localhost:8000
npm run dev
```
